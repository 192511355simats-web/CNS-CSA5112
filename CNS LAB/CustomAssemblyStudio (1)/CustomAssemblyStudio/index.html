Custom Assembly Studio & Architecture Reference

This studio implements the complete compiler pipeline and cycle-accurate execution engine for a custom 16-bit/8-bit processor architecture.

The 7-Stage Compiler Pipeline
  1. Source Code: Assembly text written in the IDE editor.
  2. Lexical Analyzer: Converts character streams into structured tokens.
  3. Syntax Analyzer: Generates Abstract Syntax Trees (AST) and validates grammar.
  4. Semantic Analyzer: Resolves label symbols and validates register bounds.
  5. Intermediate Representation: Emits Three-Address Code (TAC) Quadruples.
  6. Code Generator: Packs instructions into 3-byte machine words.
  7. Machine Code: Emits raw binary hex streams loaded into RAM.
